# Matplotlib Nord Dark Style

A custom Matplotlib style based on the **Nord** color palette — a calm, arctic-inspired dark theme.

---

## Colors

| Element | Nord Color |
|---|---|
| Background | Polar Night 2 (darkest) |
| Grid lines | Polar Night 3 |
| Axis ticks (X & Y) | Polar Night 4 |

### Plot color cycle

1. Snow Storm 3 (darkest snow)
2. Frost Blue (Nord blue)
3. Aurora colors (red, orange, yellow, green, purple)

---

## Typography

| Element | Font |
|---|---|
| X & Y tick labels | JetBrains Mono Light |
| X & Y axis labels | Avenir |
| Title | Norwester |

---

## Layout

- Grids are rendered **below** plot elements (`zorder`)
- Grid style: subtle, using Polar Night 3 to avoid visual noise
